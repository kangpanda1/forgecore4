# forgecore4

A standalone, GitHub-compatible git forge: one process serving git smart HTTP (upload-pack v2, receive-pack v0), a REST v3 API (/api/v3), the GraphQL v4 API (/api/graphql) and an MCP endpoint (/mcp), with its own store and no UI.

Entry for make.fun github-core-clone-01.

MIT licensed. Run with `node main.ts` (Node 22, standard library only).
